# Varnaya Exim

> Website for Varnaya Exim Business

A modern, responsive website built with cutting-edge web technologies to showcase and manage Varnaya Exim's business operations.

## 🚀 Features

- **Modern UI/UX**: Built with React and Tailwind CSS for a sleek, professional design
- **3D Graphics**: Interactive 3D elements powered by Three.js and React Three Fiber
- **Smooth Animations**: Fluid animations with Framer Motion and GSAP
- **Type Safe**: Full TypeScript support for reliable code
- **Performance Optimized**: Built with Next.js 14 for optimal performance
- **Analytics**: Integrated Vercel Analytics for monitoring
- **Responsive Design**: Mobile-first, fully responsive layout

## 🛠️ Installation

### Prerequisites
- Node.js 18+ or higher
- npm or yarn package manager

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sourabhmast/varnaya-exim.git
   cd varnaya-exim
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.

## 📦 Available Scripts

- Manage Three.js scenes in your 3D components
